# Music Tracks for Memory Video Feature

Drop 3–5 royalty-free MP3 files here. Expected filenames (must match `music-tracks.ts`):

| File | Genre |
|------|-------|
| `cinematic.mp3` | Cinematic |
| `joyful.mp3` | Joyful |
| `nostalgia.mp3` | Nostalgia |
| `ambient.mp3` | Ambient |
| `celebration.mp3` | Celebration |

## Where to get royalty-free tracks

- **Pixabay Audio** — https://pixabay.com/music/ (free, no attribution required)
- **Free Music Archive** — https://freemusicarchive.org/ (check license per track)
- **ccMixter** — https://ccmixter.org/

## Requirements

- Format: MP3 (128 kbps or higher)
- Duration: 90–120 seconds recommended (video is ~60–80 s; audio is trimmed with `-shortest`)
- Size: ≤ 2 MB per file
